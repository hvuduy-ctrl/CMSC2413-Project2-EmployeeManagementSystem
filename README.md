# Employee Management System

## About the Project

This is my Project 2 for CMSC 2413 – Visual Programming.

The Employee Management System is a simple Windows Forms application developed using C#. It allows users to manage employee information and calculate total salaries.

## Features

- Add new employees
- Update employee information
- Delete employees
- Search employees by ID or name
- Calculate total salary (Salary + Bonus)
- Validate user input

## OOP Concept

This project demonstrates **Encapsulation**, one of the four principles of Object-Oriented Programming.

The `Employee` class uses private fields and public properties to protect employee data and prevent invalid salary values.

## Technologies Used

- C#
- Windows Forms
- .NET Framework 4.8
- Visual Studio

## How to Run

1. Download or clone this repository.
2. Open `EmployeeManagementSystem.slnx` in Visual Studio.
3. Build the solution.
4. Press `F5` to run the application.
